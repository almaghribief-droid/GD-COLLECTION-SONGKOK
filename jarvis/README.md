# GD COLLECTION JARVIS AI

Phone-first assistant project for GD COLLECTION.

## Project status
This folder is the project workspace. The app is not deployed yet.

## Planned first release
- Responsive web dashboard that can be installed from Android Chrome as a PWA.
- Indonesian-language assistant interface with optional browser text-to-speech.
- Product catalog and customer/lead records.
- Backend API and persistent database.
- Authentication before any real customer data is stored.
- Optional AI provider integration through a server-side secret; never commit API keys.

## Safety and deployment notes
- This repository is public. Do not commit passwords, API keys, customer phone numbers, or private sales records.
- Do not expose an unauthenticated CRM to the public internet.
- Confirm hosting and database pricing/limits before deployment.
- Shopee integration is not included; it requires supported official access.

## Current status
Planning/workspace only. No live service, Android APK, hosting, or Shopee connection has been created yet.
